How I Automated My Internship Attendance (And Why It Was Kinda Illegal)

A tale of summer vacations, mandated internships, a terrible memory, and a silent Python script that solved CAPTCHAs and faked coordinates.

It was summer vacation. But instead of sleeping in, the university required us to complete a mandatory internship and log our daily check-in and check-out times on the university LMS portal.

As a developer, my laptop was always open and I was working hard. But my memory was awful. I forgot to check in multiple times, made late check-ins when I was already deep in code, and regularly forgot to check out at the end of the day.

Fearing I'd lose credit for work I was actually doing just because I couldn't remember to click a button, my internal "ADHD-driven urge to spend 8 hours automating a task that takes 2 seconds" kicked in.

The result was the PAF-IAST LMS Attendance Bot.

The Anatomy of the Hack

To make the check-in bulletproof, I needed to automate three main steps:

  1. Auto CAPTCHA Solver: The LMS login portal required solving a security verification code. I integrated an OCR API to screenshot, read, and type in the captcha code automatically.
  2. Geolocation Injection: The LMS logged location. If I checked in from home, it would fail. I used Chrome DevTools Protocol to spoof my browser's GPS coordinates to match our internship location in Abbottabad.
  3. Silent Background Run: I wrapped the script in a windowless VBScript launcher and set up Windows Task Scheduler to run it silently twice a day, bypassing battery restrictions so it triggers even when my laptop is unplugged.

from selenium import webdriver
from selenium.webdriver.common.by import By

def mark_attendance(action):
    options = webdriver.ChromeOptions()
    options.add_argument("--headless")
    driver = webdriver.Chrome(options=options)
    
    # Spoof geolocation coordinates to match the office in Abbottabad
    driver.execute_cdp_cmd("Emulation.setGeolocationOverride", {
        "latitude": 34.1688,
        "longitude": 73.2215,
        "accuracy": 100
    })
    
    driver.get("https://lms.university.edu/login")
    
    # Captcha solving via OCR API screenshot
    captcha_img = driver.find_element(By.ID, "captcha").screenshot_as_png
    captcha_code = solve_ocr(captcha_img)
    
    driver.find_element(By.ID, "username").send_keys("student_id")
    driver.find_element(By.ID, "password").send_keys("lms_password")
    driver.find_element(By.ID, "captcha_input").send_keys(captcha_code)
    driver.find_element(By.ID, "login_btn").click()
    
    # Click check-in / check-out button dynamically
    driver.find_element(By.CLASS_NAME, f"{action}-btn").click()
    driver.quit()

Why it was "Kinda Illegal"

Strictly speaking, spoofing your browser's physical location and using automated agents to bypass security verifications like CAPTCHAs violates university and LMS terms of service. But as a project built for fun and convenience, it was a major success.

I went from missing check-ins to having a perfect, silent background agent that logged check-in and check-out times with absolute, computerized precision.

The Result

The repository is open source on GitHub: attendance-automation. Building this taught me how to bypass CAPTCHAs, inject browser overrides, and integrate windows tasks—all because of my terrible memory.
